# houserules brand

The mark is a lowercase **h** drawn as a house: the tall wall, the sloped roof, the door.
One shape, one colour.

| File | Use |
|---|---|
| `mark.svg` | The mark in `currentColor`, for inline use in UI |
| `mark-black.svg` / `mark-white.svg` | The mark on light / dark backgrounds |
| `favicon.svg` | 16px pixel-aligned version; switches to white in dark mode |
| `circle.svg` | Avatar / social image (black circle) |
| `app-icon.svg` / `app-icon-teal.svg` | App tiles (radius 22.5% of size) |
| `wordmark-black.svg` / `wordmark-white.svg` | Mark + name, text outlined (no font needed) |

Rules: keep clear space of at least half the mark's width around it; don't rotate, outline,
add effects or recolour it outside black, white and the brand teal `#0f766e`.

`concepts/` holds the rejected explorations, for reference.
